# Individual Proposal Submission

Each student should create a separate Markdown file named `your-github-username.md` in this folder. Replace `your-github-username` with your GitHub username. For example, the file for `alexmba` would be `submissions/alexmba.md`. In GitHub, choose **Add file > Create new file** and enter the full path and filename.

Use this outline in your file:

```markdown
# Market-entry recommendation

## Target customer
Name a specific customer segment and why it is a sensible group to test first.

## Assumption to validate
State what you do not yet know about this customer or their interest.

## Low-cost launch test
Describe a practical test and the signal that would make you continue, revise, or stop.
```

Create the file on your own branch, commit it with a clear description, and open a pull request to the class repository's `main` branch. If you are working from a fork, make the class repository the pull request's destination. Do not edit another student's file or the shared business case. The instructor may assign you a classmate's pull request to review.

The Python market-test script is separate local practice. Its fictional numbers are not market research and do not need to be included in your proposal.

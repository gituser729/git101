# Harbor & Pine: A Market-Entry Proposal

## Business context

Harbor & Pine is a fictional direct-to-consumer home-goods company considering a launch of reusable insulated lunch bags. The team has limited research and wants to learn whether a focused launch is worth pursuing before committing a large budget.

## Current proposal

- **Objective:** Test whether a clearly defined customer group is interested in a durable, well-designed lunch bag.
- **Constraint:** The team has a modest pilot budget and should avoid assuming demand before testing it.
- **Open question:** Which customer segment and launch approach should the team prioritize?

## Team decision

Recommend a customer segment and a low-cost way to test demand before a full launch. State the assumption to validate and what evidence would suggest continuing, revising, or stopping. Put your individual recommendation in a new file, following the format in [`submissions/README.md`](../submissions/README.md), rather than editing this shared case file.

## Python market-test exercise

Download [`pilot_check.py`](./pilot_check.py) and open the local copy in a Python 3 environment. Run it, change the sample signup count or target conversion rate, and run it again. Observe how the calculated conversion rate affects the recommendation. The figures are fictional and for practice only. This simplified example is not enough evidence by itself to make a real launch decision.

## Discussion prompts

- What makes your proposed customer segment a useful starting point?
- What evidence would help validate the key assumption?
- What would be a reasonable next step if the test results are mixed?

## Exercise note

This is a fictional classroom case. Treat recommendations as hypotheses to test, not as established market facts. Create your own submission file in a branch (or fork), commit it with a clear description, and submit it for review.
